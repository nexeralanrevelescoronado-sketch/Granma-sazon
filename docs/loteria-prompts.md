# Lotería de Granma: prompts para las 54 cartas

Pedido del dueño (28 nov 2026). Las genera el dueño con ChatGPT o Gemini y las manda; se revisan, se optimizan a WebP y entran al juego.

## Cómo usarlos

1. Copia el prompt de cada carta tal cual (es el mismo estilo para todas; solo cambia el «Elemento central»).
2. Pide la imagen **vertical 2:3** (por ejemplo, 1024 × 1536).
3. Guárdala con el nombre que dice cada carta (por ejemplo, `01-elote.png`) y mándamelas, de una en una o todas juntas.
4. Si una sale con letras, con algo raro o muy parecida a otra baraja, pide que la rehaga.
5. La app pone encima el número y el nombre en español o inglés, por eso la imagen va **sin texto**.
